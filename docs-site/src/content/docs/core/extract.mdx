---
title: Extract fields
description: Extract typed fields from shared text or file evidence.
---

Use extraction to pull named, typed values (totals, dates, durations, lists)
out of text or document evidence, with confidence and source offsets for each
answer. `AI.experimentalExtract` reads one evidence state and a field map, and
returns one validated answer per field. It is separate from
[structured output](../structured-output/) and [decisions](../decide/).

```swift
import SwiftAISDK

let provider = try AIProviders.openAI()
let result = try await AI.experimentalExtract(
    model: try provider.extractionModel("gpt-5.5"),
    state: .text("Invoice total: 1200 yen. Issued on 2026-11-14."),
    fields: [
        "total": .init(type: .number, unit: "JPY", integer: true),
        "issued": .init(type: .date)
    ],
    referenceDate: "2026-11-14"
)
let total = result.answers["total"]?.value
```

The state uses the same `AIDecisionState` values as decisions: `.text`, `.object`
or ordered `.parts` with text, JSON and file evidence.

## Providers

| Provider | Factory | How extraction runs |
| --- | --- | --- |
| [OpenAI](../../providers/openai/) | `AIProviders.openAI()` | Language-model adapter with structured output. |
| [Anthropic](../../providers/anthropic/) | `AIProviders.anthropic()` | Language-model adapter with structured output. |
| [Google Generative AI](../../providers/google-generative-ai/) | `AIProviders.google()` | Language-model adapter with structured output. |
| [AI Gateway](../../providers/gateway/) | `AIProviders.gateway()` | Native extraction routes configured by Gateway. |
| [ScaleDown](../../providers/scaledown/) | `AIProviders.scaleDown(configuration:)` | Native extraction model; text fields and lists of text only. |

Each factory exposes `extractionModel(_:)`. The modular packages expose the same
method on their native provider types, for example
`OpenAIProvider(configuration:)` from `SwiftAIOpenAI`.

## Fields and answers

Fields support text, number, date, time, datetime, duration and lists of text,
number or date items. Field instructions, units, integer/decimal constraints and
an optional calendar reference date guide extraction. An absent value is `nil`,
with a separate `guess` where the model can supply one. Answers retain confidence,
`pNull`, source evidence, usage and provider metadata. Text source offsets count
UTF-16 code units. File sources identify the original evidence part. The facade
normalizes empty strings and empty lists to missing values while preserving
whitespace in nonempty strings and retaining answer metadata.

## Lifecycle and telemetry

Use `onStart` and `onEnd` for application callbacks. An opt-in `telemetry`
integration receives `ai.extract` operation events and
`ai.extract.doExtract` model-call events. The integration receives filtered
runtime context and redacted file URLs and references. Request headers and
provider options remain available to the application callback. A failure emits
an error event, and the success callback fires after answer validation.

## Errors and limitations

The facade validates input before model work and checks every returned answer.
Unsupported field types, malformed/incomplete answers and refusals throw typed
errors for the complete call. Retry settings and abort signals follow the
shared conventions in [Error handling](../error-handling/). URL evidence uses
protected downloads (see [Files](../files/)); an explicit `download` function
can supply an application-owned downloader.

## Registries and model strings

Use `AIProviderRegistry.extractionModel("provider:model")` for a registered
provider. With the umbrella package, `AI.experimentalExtract(model: "…")`
resolves the string through `AIDefaultProvider`, which uses Gateway by default.
Supply a model that the configured provider supports for extraction.

Register an extraction alias with `AIProviders.customProvider(extractionModels:)`.
An alias accepts `.model(existingModel)` or a model ID string. In standalone
packages, supply a fallback provider for string IDs. The umbrella resolves
string IDs through `AIDefaultProvider`.
