## Package

`@ai-sdk/cartesia`

## Factories

`AIProviders.cartesia`

## Capabilities

- Transcription
- Speech

Known `ink-whisper` and dated `ink-whisper-*` snapshots use REST batch
transcription. Every other current or future ID uses the existing streaming
protocol; select `streamingTranscriptionModel(...)` for those models.

## Rotating credentials

The native provider settings accept an optional `apiKeyProvider` asynchronous
throwing closure. The provider resolves it for each authenticated request;
static keys and explicit custom authentication headers remain supported.
Supplier failures stop the request before it reaches the transport.

## Current request and response behavior

Sonic speech accepts `volume` (0.5...2), a declared `emotion`, `locale`,
`normalization`, and `pronunciationDictionaryId` in `providerOptions.cartesia`.
`locale` overrides the generic language with a warning, and cannot be combined
with a provider-specific language. Speed, volume and emotion share one generation
configuration. Ink 2 streaming accepts repeated `keyterms` (at most 100),
`turnStartThreshold`, `turnEagerEndThreshold`, `turnEndThreshold` and integer
`turnEndTimeoutMs`. Turn thresholds are omitted with warnings when turn detection
is disabled. The documented 1200-character keyterm budget remains a service limit;
the published schema validates the count.


## Notes

Cartesia REST speech, batch transcription, and Ink 2 streaming transcription mirror upstream 3.0.71: `CARTESIA_API_KEY`, Bearer auth, `Cartesia-Version` default `2026-03-01`, custom headers and Swift base-URL override, versioned user-agent suffix, speech/transcription aliases, `/tts/bytes` JSON speech, `/stt` multipart batch transcription, and `/access-token` plus duplex `/stt/turns/websocket` or `/stt/websocket` streaming. Streaming supports raw PCM/G.711 encodings, server turn detection or explicit finalization, partial/final events, raw chunks, token-redacted metadata, cancellation, and an injectable `AIDuplexWebSocketTransport`. Full realtime speech-session generation remains a broader protocol gap; `ink-2` batch calls still fail locally before network I/O. The 2026-10-18 pass: Only ink-whisper and dated ink-whisper-* IDs are batch-only. Other current and future IDs use the existing duplex transcription protocol. The 2026-11-01 reviewed delta adds native per-request async credentials and current portable request/stream fixes where applicable; see WeeklyUpstreamAudit20261101 for exact package dispositions and retained gaps. The 2026-11-08 reviewed delta and retained gaps are documented in WeeklyUpstreamAudit20261108; no full-package or live-service parity is implied.
