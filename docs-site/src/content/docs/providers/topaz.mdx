Topaz Labs image and video enhancement: upscale and restore an existing image with Wonder, or enhance a video with Proteus or Starlight as a resumable job. Topaz does not generate media from text.

Provider ID: `topaz` · Upstream package: `@ai-sdk/topaz`

## Package

The complete `SwiftAISDK` umbrella (`import SwiftAISDK`) already includes this provider.
For a smaller dependency graph, add only core and `swift-ai-topaz`:

```swift
// Package.swift
.package(url: "https://github.com/SwiftAISDK/swift-ai-core.git", from: "1.5.0"),
.package(url: "https://github.com/SwiftAISDK/swift-ai-topaz.git", from: "1.1.2"),

// Target dependencies
.product(name: "SwiftAI", package: "swift-ai-core"),
.product(name: "SwiftAITopaz", package: "swift-ai-topaz"),
```

```swift
import SwiftAI

```

Versions shown are from the tested 3.4.0 release set. See [Install](../../getting-started/install/) for credentials and native factory settings.

## Quick start

```swift
import SwiftAISDK

let topaz = try AIProviders.topaz()
let model = try topaz.imageModel("wonder-3.5")
let result = try await model.generateImage(
    "",
    size: "4000x3000",
    files: [ImageInputFile(url: "https://example.com/input.png")],
    providerOptions: ["topaz": ["enhancementStrength": "medium", "outputFormat": "png"]]
)
print(result.urls.first ?? "")
```

For the modular packages, use `import SwiftAI` and `import SwiftAITopaz`, then
`try AIProviders.topaz(configuration: TopazProviderSettings(...))`. The native factory
requires a configuration argument; `TopazProviderSettings()` reads `TOPAZ_API_KEY`.

Topaz enhances existing images and videos; it does not generate from text. The API key
is resolved when the provider is created and sent as `x-api-key`. It is withheld from
upload URLs and from downloads on other origins.

## Enhance an image

`wonder-3.5` is sent as `Wonder 3.5`; other IDs are forwarded unchanged. One input
image is processed per call: pass a URL with `ImageInputFile(url:)` (Topaz fetches it)
or bytes with `ImageInputFile(data:mediaType:)` (uploaded). An empty prompt means no
prompt. A nonempty prompt, `aspectRatio`, `seed`, masks, extra files and a `count`
above one produce warnings.

Options under `providerOptions["topaz"]`:

| Option | Behavior |
| --- | --- |
| `outputWidth`, `outputHeight` | Integers from 1 to 32000; each overrides that dimension of `size`. |
| `outputFormat`, `cropToFill` | `jpeg`, `jpg`, `png`, `tiff` or `tif`; Boolean cropping. |
| `enhancementStrength` | `low`, `medium` or `high`. |
| `grain`, `grainDensity`, `grainModel`, `grainSize`, `grainStrength` | Boolean; 0–1; `silver`, `gaussian` or `grey`; 1–5; 0–1. |
| `inputWidth`, `inputHeight` | Positive integers; Topaz infers them otherwise. |
| `webhookUrl` | Notification URL; the call still polls for completion. |
| `pollIntervalMillis`, `pollTimeoutMillis` | Positive integers; defaults 2000 and 600000. |

The finished image is downloaded into `base64Images` and its URL kept in `urls`.
`providerMetadata["topaz"]["images"][0]` holds `processId` and any reported `credits`,
`width`, `height` and `format`. Failed or cancelled jobs throw. If polling is cancelled
or times out, the SDK attempts to cancel the Topaz job.

## Enhance a video

```swift
let video = try await AI.generateVideo(
    model: topaz.videoModel("proteus"),
    request: VideoGenerationRequest(
        prompt: "",
        inputReferences: [ImageInputFile(url: "https://example.com/input.mp4", mediaType: "video/mp4")],
        resolution: "3840x2160",
        providerOptions: ["topaz": ["auto": "Auto"]]
    ),
    poll: VideoGenerationPollOptions(intervalMilliseconds: 5_000, timeoutMilliseconds: 600_000)
)
print(video.urls.first ?? "")
```

`proteus` maps to `prob-4` and `starlight-precise-2.6` to `slp-2.6`; raw Topaz model
IDs also work. Videos use `/video/express`: Topaz fetches URL inputs itself, and
supplied bytes are uploaded to the returned presigned URL. A failed upload triggers a
best-effort job cancellation.

Set `resolution`, or `output.width`/`output.height`, unless you supply source
dimensions. All options below go under `providerOptions["topaz"]`:

- `source`: all-or-nothing `width`, `height`, `duration` and `frameRate`, plus optional
  `frameCount` (defaults to duration × frame rate; set it for variable frame rates) and
  `container` (otherwise inferred from the media type or URL). Starlight requires
  source metadata. The SDK does not inspect video bytes.
- `output`: `width`, `height`, `frameRate`, `audioCodec` (`AAC`, `AC3`, `PCM`),
  `audioBitrate`, `audioTransfer` (`Copy`, `Convert`, `None`), `videoEncoder` (`AV1`,
  `H264`, `H265`, `ProRes`, `VP9`), `videoProfile`, `videoBitrate`,
  `dynamicCompressionLevel`, `cropToFit` and `container` (`mp4`, `mov`, `mkv`, `avi`,
  `webm`). These override `resolution` and `fps`. Audio defaults to `Copy` with `AAC`;
  `audioTransfer: "None"` omits the codec. `ProRes` forces `mov`; `AV1` and `VP9` force
  `mp4`.
- Proteus: `videoType`, `auto`, `fieldOrder`, `focusFixLevel`, `compression`,
  `details`, `prenoise`, `noise`, `halo`, `preblur`, `blur`, `grain`, `grainSigma`,
  `grainSize`, `grainType`, `recoverOriginalDetailValue`.
- Starlight: `sharpness` (1–5), `videoBitDepth`, `videoCodec` (`ffv1`, `prores`,
  `vp9`), `videoProfile` (`420`, `422`, `444`), `watermark`.
- `filter` adds or overrides model settings; `additionalFilters` adds interpolation or
  other filters.

## Persist and resume a video job

`AI.generateVideo` submits and polls for you. To submit without waiting, call
`AI.startVideo(model:request:)` and persist its JSON `operation` (`requestId` and
`outputContainer`); later call `AI.getVideoStatus(model:operation:)`, which returns
`.pending`, `.completed` or `.failed`. Unknown Topaz states stay pending. Calling the
video model's unary method directly is unsupported.

Start metadata reports `requestId` and an optional `estimatedCredits` (an estimate, not
a billed amount). Completed metadata reports `credits` (the lower bound of the final
estimate), the estimate, output size and expiry when provided. Failed status includes
Topaz's message and error code; HTTP errors keep the original body and validation
details. Stopping polling does not cancel a running video job, because Topaz exposes no
video cancellation API; keep the operation to resume. There is no video webhook
support.

The runnable example is `Examples/Sources/EnhanceWithTopaz/main.swift`:
`swift run --package-path Examples EnhanceWithTopaz image <source-url> 4000x3000` or
`video <source-url> 3840x2160`. Running it calls the Topaz API.

## Rotating credentials

The native `TopazProviderSettings` accepts `apiKeyProvider`, an async throwing closure
resolved before each authenticated request. A supplier failure stops the request before
it is sent. `TopazProviderSettings(environment:)` supplies a custom environment map.
