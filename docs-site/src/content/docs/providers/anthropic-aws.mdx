## Package

`@ai-sdk/anthropic-aws`

## Factories

`AIProviders.anthropicAWS`

## Capabilities

- Language
- Files
- Skills

The current shared Messages behavior exposes normalized citations while retaining raw citation metadata, avoids duplicate web-search sources, preserves tool definitions for `toolChoice: none`, and falls back to automatic tool choice with a warning under manual thinking. Tool-result file references and tool-search error transcripts use the same conversion as the direct Anthropic provider. AWS authentication, signing, regional routing, and workspace headers retain their existing behavior.


## Notes

Anthropic AWS mirrors upstream 2.0.81 request signing, regional endpoint handling, and the shared Anthropic Messages behavior represented by the Swift provider. JavaScript AWS credential-provider hooks remain runtime-specific. The 2.0.41 pass inherits the shared Anthropic 4.0.49 system-option, thinking, model-recognition, and beta-header behavior through AWS signing. The 2026-09-27 delta is version-identity-only and continues to inherit shared Anthropic behavior. Generated-host regions are validated as complete single DNS labels; custom endpoints bypass unused region validation. The 2026-10-11 pass: Inherits current Messages/Haiku behavior; non-ASCII headers remain outgoing but are excluded from SigV4 signing. The 2026-10-18 pass: Shared Messages citation, thinking/tool-choice and tool-result file-reference behavior follows the current Anthropic adapter, including the native AWS provider-reference namespace.

Factory argument requirements are defined by the public Swift factory signatures. Use [Public symbols](/reference/generated/public-symbols/) when you need the exact initializer or factory declaration.
