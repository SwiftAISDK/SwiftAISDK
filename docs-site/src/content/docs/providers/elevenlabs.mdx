ElevenLabs text-to-speech (including WebSocket streaming and multi-speaker dialogue) and Scribe speech-to-text. The provider also exposes music, sound effects, voice changer, voice isolator and dubbing.

Provider ID: `elevenlabs` · Upstream package: `@ai-sdk/elevenlabs`

## Package

The complete `SwiftAISDK` umbrella (`import SwiftAISDK`) already includes this provider.
For a smaller dependency graph, add only core and `swift-ai-elevenlabs`:

```swift
// Package.swift
.package(url: "https://github.com/SwiftAISDK/swift-ai-core.git", from: "1.6.0"),
.package(url: "https://github.com/SwiftAISDK/swift-ai-elevenlabs.git", from: "1.3.0"),

// Target dependencies
.product(name: "SwiftAI", package: "swift-ai-core"),
.product(name: "SwiftAIElevenLabs", package: "swift-ai-elevenlabs"),
```

## Quick start

```swift
import SwiftAISDK

let provider = try AIProviders.elevenLabs()
let model = try provider.speechModel("eleven_multilingual_v2")
let result = try await model.generateSpeech(
    "Welcome back! Your order is on its way.",
    voice: "21m00Tcm4TlvDq8ikWAM",
    format: "mp3"
)
let mp3 = result.audio
```

For a smaller dependency graph, use `import SwiftAI` and `import SwiftAIElevenLabs`
with the native factory `AIProviders.elevenLabs(configuration: ElevenLabsProviderSettings())`.
The native factory requires the configuration argument; `ElevenLabsProviderSettings()`
reads `ELEVENLABS_API_KEY` from the environment. Requests authenticate with the
`xi-api-key` header.

## Speech

`speechModel(_:)` calls `/v1/text-to-speech/{voice}`. Without a `voice`, the SDK
uses `21m00Tcm4TlvDq8ikWAM`. `format` accepts `mp3` (sent as `mp3_44100_128`, the
default), `mp3_32` to `mp3_192`, `pcm` (`pcm_44100`), `ulaw` (`ulaw_8000`) and
`wav` (`wav_44100`); any other value, such as `pcm_24000`, is passed through as a
native ElevenLabs output format.

Options under `providerOptions["elevenlabs"]`:

| Key | Purpose |
| --- | --- |
| `voiceSettings` | `stability`, `similarityBoost`, `style`, `useSpeakerBoost` (the request `speed` is sent as `voice_settings.speed`) |
| `languageCode` | Language hint (the request `language` takes precedence) |
| `pronunciationDictionaryLocators` | Pronunciation dictionaries to apply |
| `previousText`, `nextText`, `previousRequestIds`, `nextRequestIds` | Continuity context |
| `applyTextNormalization`, `applyLanguageTextNormalization` | Normalization controls |
| `enableLogging`, `seed` | Logging opt-out and deterministic sampling |
| `withTimestamps` | Return character alignment (see below) |

`instructions` is not supported and produces a warning.

### Timestamps

Set `withTimestamps: true` to get character alignment from Text to Speech or
Text to Dialogue, or lyric word timings from music. Speech results still contain
decoded audio, and `providerMetadata["elevenlabs"]` holds `alignment`,
`normalizedAlignment` and `voiceSegments`. Music uses `/v1/music/detailed` and
returns `wordTimestamps` with `word`, `startMs` and `endMs`.

### Dialogue

`eleven_v4` always uses Text to Dialogue with the supplied text and voice. For
multiple speakers on `eleven_v3*` or `eleven_v4*`, pass
`providerOptions["elevenlabs"]["inputs"]` as an array of objects with non-empty
`text` and `voiceId`; it replaces the request text and voice. Dialogue maps
stability and similarity settings and warns about ignored instructions, speed and
unsupported voice settings.

## Transcription

```swift
let scribe = try provider.transcriptionModel("scribe_v2")
let transcript = try await scribe.transcribe(
    audio: audioData,
    fileName: "call.m4a",
    mimeType: "audio/mp4",
    providerOptions: ["elevenlabs": ["languageCode": "en", "tagAudioEvents": true]]
)
print(transcript.text)
```

Transcription calls `/v1/speech-to-text`. Diarization is on by default, including
when other provider options are set; set `diarize: false` to disable it. Other keys:
`languageCode`, `tagAudioEvents`, `numSpeakers`, `timestampsGranularity` and
`fileFormat`. Every word, including spacing, becomes a segment. Words are kept in
`providerMetadata["elevenlabs"]["words"]` with `text`, `type`, `start`, `end`,
`speaker_id` and `characters`; other response fields such as `logprob` remain in
the raw response body. The reported `audio_duration_secs` is used as the duration
when present.

`scribe_v2_realtime` is a streaming-only model and is rejected for batch
transcription; realtime transcription is not available yet. A `streaming` option
is validated but ignored by batch transcription, with an `unsupported` warning.

Set `sourceUrl` to let ElevenLabs fetch the audio itself. The request then omits
the file; any non-empty local audio is ignored with a warning.

## Streaming speech

`streamingSpeechModel(_:)` opens a WebSocket session and accepts text
incrementally. See [Stream speech](../../core/stream-speech/) for the facade.

```swift
let model = try provider.streamingSpeechModel("eleven_flash_v2_5")
let result = try AI.experimentalStreamSpeech(
    model: model,
    request: StreamingSpeechRequest(
        text: .chunks(["Hello ", "from Swift."]),
        voice: "21m00Tcm4TlvDq8ikWAM",
        outputFormat: AIStreamingAudioFormat(mediaType: "audio/pcm", sampleRate: 24_000)
    )
)
for try await chunk in try result.audioStream {
    // Feed each chunk to an audio player that accepts the selected format.
    _ = chunk
}
```

- Consume exactly one of `audioStream`, `fullStream` or the awaited final
  metadata; awaiting metadata first drains the stream. There is no replay buffer.
- A stream that produces no audio throws `AINoSpeechGeneratedError`.
- Cancelling the result, aborting the request or leaving the loop early releases
  the input producer and socket.
- Portable output formats include MP3, PCM, μ-law, A-law and Ogg Opus.
- `providerOptions["elevenlabs"]["streaming"]` accepts `autoMode`,
  `chunkLengthSchedule` (each value 50–500), `enableSsmlParsing`,
  `inactivityTimeout` (1–180 seconds), `syncAlignment` and a native `outputFormat`.
- Text is flushed at word or CJK punctuation boundaries. Usage counts Unicode
  code points. Idle keepalives are sent unless you set `inactivityTimeout`.
- The API key travels in the first WebSocket message and is left out of request
  metadata. `withTimestamps` is unsupported here; use `syncAlignment`.

Streaming `eleven_v3*` and `eleven_v4*` models require
`providerOptions["elevenlabs"]["dialogue"]["voices"]` (1–10 voice IDs). Each
`SpeechTextPart.voice` selects a listed speaker; a changed voice or `newTurn: true`
starts a new turn. `eleven_v3_conversational` accepts exactly one voice.

## Music and sound effects

Use the dedicated models with [Generate audio](../../core/generate-audio/):

```swift
let music = try provider.music("music_v1")
let track = try await music.generateAudio("Upbeat lo-fi beat for studying", durationSeconds: 30)

let effects = try provider.soundEffects("eleven_text_to_sound_v2")
let whoosh = try await effects.generateAudio("A fast whoosh", durationSeconds: 2)
```

`music_*` and `eleven_text_to_sound*` IDs also work through `speechModel(_:)`.
Music options: `musicLengthMs` (3,000–600,000), `forceInstrumental`, `seed`, or a
snake_case `compositionPlan`, which replaces the prompt and cannot be combined with
`musicLengthMs` or `forceInstrumental`. Sound effect options: `durationSeconds`
(0.5–30), `promptInfluence` (0–1) and `loop`. These models reject streaming speech.

## Voice changer, voice isolator and dubbing

`voiceChanger(_:)` (default `eleven_multilingual_sts_v2`) and `voiceIsolator(_:)`
(default `audio-isolation`) return audio transformation models; see
[Transform audio](../../core/transform-audio/). `dubbing()` returns an
`ElevenLabsDubbingClient` for dubbing jobs; see [Dubbing](../../core/dubbing/).

## Errors

API errors accept object, validation-array and string `detail` shapes as well as
legacy `error` objects. Typed errors expose the provider message and code and keep
the full body, status and response headers.

## Rotating credentials

`ElevenLabsProviderSettings(apiKeyProvider:)` takes an async throwing closure that
is called before every authenticated HTTP request and WebSocket connection, so
short-lived keys refresh without recreating the provider. If the closure throws,
the request is not sent.
