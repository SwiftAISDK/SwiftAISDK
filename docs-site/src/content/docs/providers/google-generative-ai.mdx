Gemini models through the Gemini API (Google AI Studio): text with thinking, tools and Google Search grounding, embeddings, Gemini and Imagen images, TTS speech, Veo video, files, decisions, extraction, Gemini Live realtime and batches. For Gemini on Google Cloud, use the Google Vertex AI provider.

Provider ID: `google.generative-ai` · Upstream package: `@ai-sdk/google`

## Package

The complete `SwiftAISDK` umbrella (`import SwiftAISDK`) already includes this provider.
For a smaller dependency graph, add only core and `swift-ai-google`:

```swift
// Package.swift

.package(url: "https://github.com/SwiftAISDK/swift-ai-google.git", from: "1.4.0"),

// Target dependencies
.product(name: "SwiftAI", package: "swift-ai-core"),
.product(name: "SwiftAIGoogle", package: "swift-ai-google"),
```

```swift
import SwiftAI

```

## Quick start

```swift
import SwiftAISDK

let google = try AIProviders.google()
let model = try google.languageModel("gemini-2.5-flash")
let result = try await model.generateText("Explain how rainbows form in two sentences.")
print(result.text)
```

`AIProviders.google(settings:)` returns the native `GoogleGenerativeAIProvider`.
For a smaller dependency graph, use `import SwiftAI` and `import SwiftAIGoogle`
with `AIProviders.google(configuration: GoogleProviderSettings())`. The native
factory requires the configuration argument; rotating credentials need the
native settings.

The API key is read from `GOOGLE_GENERATIVE_AI_API_KEY`, then `GOOGLE_API_KEY`,
then `GEMINI_API_KEY`, and sent in the `x-goog-api-key` header. Requests go to
`https://generativelanguage.googleapis.com/v1beta` unless you set `baseURL`. For
Gemini on Google Cloud, use [Google Vertex AI](../google-vertex/).

## Provider options

GenerateContent reads these keys from `providerOptions["google"]`; other keys are
ignored:

`responseModalities`, `thinkingConfig`, `cachedContent`, `structuredOutputs`,
`safetySettings`, `threshold`, `audioTimestamp`, `labels`, `mediaResolution`,
`imageConfig`, `retrievalConfig`, `serviceTier` and `continuationToken`.

```swift
let result = try await model.generateText(
    "Draft a product description for a hiking backpack.",
    options: LanguageGenerationOptions(providerOptions: [
        "google": [
            "thinkingConfig": ["thinkingBudget": 1024],
            "safetySettings": [
                ["category": "HARM_CATEGORY_HARASSMENT", "threshold": "BLOCK_ONLY_HIGH"],
            ],
        ],
    ])
)
```

- `responseModalities` accepts `TEXT`, `IMAGE` and `AUDIO`.
- `streamFunctionCallArguments`, `sharedRequestType` and `requestType` are Vertex
  options; here they are ignored with a warning.
- `serviceTier` is reported in provider metadata, falling back to the
  `x-gemini-service-tier` response header.

### Thinking

An explicit `thinkingConfig.thinkingBudget` or `thinkingConfig.thinkingLevel`
takes precedence over the portable `reasoning` option. Otherwise:

- Gemini 3 and newer map `reasoning` to a `thinkingLevel` (`low`, `medium`,
  `high`, and `minimal` or `xhigh` where the model supports them). Levels below a
  model's floor, such as `none` on models that cannot disable thinking, move up
  to the lowest supported level with a compatibility warning. Gemini 4 Hydrogen
  and Neon support `xhigh` and use `low` as their minimum.
- Gemini 2.5 maps `reasoning` to a `thinkingBudget`. `none` sends a budget of 0,
  except on Gemini 2.5 Pro, which uses its 128-token minimum.

Reasoning text is returned in `result.reasoning`, and thought signatures are
replayed from message history.

## Structured output and tools

JSON Schema output is converted to Gemini's OpenAPI-style schema, including
enums, constants, `minItems`/`maxItems` and local `$ref` expansion. A request can
combine JSON output with your own function tools: Gemini 3 automatic tool choice
uses native JSON output, and older models or forced tool choice use an internal
response tool whose arguments become the JSON text. Your real tool calls are kept
either way. Strict forced or named tools use `ANY` mode.

`GoogleTools` creates Gemini built-in tools:

```swift
let result = try await model.generate(LanguageModelRequest(
    messages: [.user("What happened in tech news today?")],
    tools: ["search": GoogleTools.googleSearch()]
))
print(result.sources)
```

Available tools: `googleSearch(searchTypes:timeRangeFilter:)`,
`enterpriseWebSearch()`, `googleMaps()`, `urlContext()`,
`fileSearch(fileSearchStoreNames:metadataFilter:topK:)`, `codeExecution()` and
`vertexRagStore(ragCorpus:topK:)`. Grounding sources appear in `result.sources`
and grounding details in `providerMetadata["google"]`. Tool failures and denials
are sent back as `functionResponse.error`. When a prompt is blocked, Gemini can
return `blockReason` and `blockReasonMessage` in
`providerMetadata["google"]["promptFeedback"]`.

## Long outputs and continuation

For models that return a `CONTINUATION` finish reason, GenerateContent continues
automatically: each request resends the prompt with the returned token, keeps
`maxOutputTokens` as a total budget, and appends the new content to the same
text (or stream). Usage sums every request; the first prompt's count is in
`providerMetadata["google"]["initialPromptTokenCount"]`, and
`groundingMetadataPerRequest` holds one grounding entry per request.

A response that stops at `MAX_TOKENS` exposes
`providerMetadata["google"]["continuationToken"]`. To resume, send the original
prompt with a larger `maxOutputTokens` and the token in
`providerOptions["google"]["continuationToken"]`. If a streamed continuation
fails, the stream reports the error and then finishes with the resumable token.

## Files and media input

Messages accept inline images, audio, video and PDFs, URLs, and references
returned by `files()`, which uploads through the Gemini resumable upload API.

Trim or sample video with `GoogleVideoMetadata`:

```swift
let clip = GoogleVideoMetadata(startOffset: "3.5s", endOffset: "12s", fps: 2)
let message = AIMessage(role: .user, content: [
    .text("Describe this clip."),
    .file(mimeType: "video/mp4", data: videoData,
          providerMetadata: ["google": ["videoMetadata": clip.jsonValue]]),
])
```

Offsets are duration strings; `fps` must be greater than 0 and at most 24.

## Embeddings, images, speech and video

- Embeddings: up to 100 values per call. Set `taskType` and `outputDimensionality`
  under `providerOptions["google"]`; the shared `dimensions` argument also works.
- Images: Gemini image models (such as `gemini-2.5-flash-image`) use
  GenerateContent and accept input images; Imagen models (such as
  `imagen-3.0-generate-002`) use `:predict`. The request `aspectRatio` is merged
  with any `imageConfig` you pass.
- Speech: `speechModel("gemini-2.5-flash-preview-tts")` returns WAV by default
  (Gemini's PCM wrapped in a WAV header); `format: "pcm"` returns raw 16-bit PCM
  with a warning. The default voice is `Kore`; custom voice IDs are rejected.
  Use `providerOptions["google"]["multiSpeakerVoiceConfig"]` for several
  speakers. The sample rate is in `providerMetadata["google"]["sampleRate"]`.
- Video: `videoModel("veo-3.1-generate-preview")` starts a long-running operation
  and polls every 10 seconds for up to 10 minutes; change this with
  `pollIntervalMs` and `pollTimeoutMs` under `providerOptions["google"]`.

## Interactions API

`interactionsModel(_:)` uses the Interactions API, and `interactionsAgent(_:)`
calls a hosted agent such as `deep-research`:

```swift
let agent = google.interactionsAgent("deep-research")
let report = try await agent.generateText("Survey recent work on solid-state batteries.")
```

Interactions supports function and built-in tools, reasoning, response history,
video input and streaming. The portable `reasoning` option maps to
`thinking_level`; `providerOptions["google"]["thinkingLevel"]` takes precedence.
Agent calls ignore generation controls and warn about each dropped setting.
Requests with `background: true` are polled until they finish.

Pass `GoogleTools.mcpServer(name:url:headers:allowedTools:)` in a request's tools
to connect a remote MCP server from an Interactions model. Gemini sends these
headers to the connector, and SDK telemetry masks each connector header value.
Raw request metadata and API error diagnostics retain the header values.

## Decisions and extraction

```swift
let decision = try await AI.experimentalDecide(
    model: try google.decisionModel("gemini-decision-1"),
    state: .text("The package arrived cracked."),
    questions: ["damaged": .boolean(instructions: "Is the package damaged?")]
)

let extraction = try await AI.experimentalExtract(
    model: try google.extractionModel("gemini-3.8-flash"),
    state: .text("The invoice total is 42 EUR."),
    fields: ["total": .init(type: .number, unit: "EUR")]
)
```

`gemini-decision-*` IDs use Google's native decisions endpoint (Choice, Score and
Boolean questions; Box and provider file references are rejected). Other IDs
passed to `decisionModel(_:)` use a Gemini structured-generation adapter, which
also supports Box. Use `nativeDecisionModel(_:)` to send any other ID to the native
endpoint.

## Realtime

`realtimeModel("gemini-3.8-live")` connects to Gemini Live over WebSockets. Use
`AIRealtimeSession.connectServer(model:sessionConfiguration:)` on a trusted server,
or an ephemeral client secret on devices. Conversation sessions are supported;
transcription-only sessions are rejected before connecting. Usage is available
from `event.usage`.

## Batches

`experimentalBatch()` runs Gemini batch jobs, including tool content and input
file metadata. Result rows are limited to 64 MiB each by default; change it with
`GoogleProviderSettings(batchResultDownloads: AIBatchResultDownloadSettings(maxLineBytes:))`.

Google's batch endpoint does not reliably enforce JSON schemas. Use
`responseFormat: .json()` for JSON mode. If your shared request carries a schema,
set `providerOptions["google"]["structuredOutputs"]` to `false` to omit it from
the wire request, then validate the batch results locally.

## Rotating credentials

`GoogleProviderSettings(apiKeyProvider:)` takes an async throwing closure that is
called before every authenticated request, including continuation requests, batch
operations, file uploads and processing polls. Upload URLs that do not need a key
receive none. If the closure throws, the request is not sent.
