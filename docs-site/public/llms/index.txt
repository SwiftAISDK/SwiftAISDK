# Introduction

Source URL: https://swiftaisdk.github.io/SwiftAISDK/

SwiftAISDK is a SwiftPM port of the provider-facing parts of Vercel AI SDK. It gives Swift apps one facade for text, durable batches, structured output, decisions, embeddings, media, streaming audio, realtime sessions, reranking, files, skills, middleware, MCP tools, and typed tool execution.

Start with a provider, pick a model, and call Swift-native model methods such as `generateText`, `streamText`, and `generateObject`. Keep provider-specific behavior in provider settings and `providerOptions`; keep application behavior in Swift types, tools, and async sequences.

## Choose Your Path

Quickstart
Generate your first response with OpenAI or any registry-backed model.

Tools
Let a model call typed Swift functions and continue the conversation.

Files
Upload, inspect, stream, and delete provider-managed files.

Providers
See every supported provider, its Swift package, factories, and capabilities.

MCP
Discover remote tools and pass them into text generation.

Decisions
Ask typed Choice, Score, and Boolean questions about text, JSON, and file evidence.

Realtime
Run bidirectional voice and text sessions with xAI, OpenAI Live, Google Gemini Live, or Gateway.

Chat
Drive a SwiftUI chat view from an observable session with streamed UI messages.

## How the Docs Are Organized

- **Start** covers installation, credentials, the first request, and the 3.0 package migration.
- **Text**, **Structured data**, **Tools and MCP**, **Search**, **Images and video**, and **Audio** are task guides for each model capability. Chat sessions sit under **Text**; agents sit under **Tools and MCP**.
- **Runtime** covers model metadata, middleware, provider files, errors, telemetry, and troubleshooting.
- **Providers** has one page per provider with its Swift package, factories, capabilities, and provider-specific behavior. The provider matrix compares them.
- **Reference** is generated from Swift symbol graphs and is best used after a guide points you to a type.

Every page is also available as Markdown for coding agents: see [`llms.txt`](https://swiftaisdk.github.io/SwiftAISDK/llms.txt), or replace a page's trailing slash with `.md`.

## Current Scope

SwiftAISDK ports the provider-facing AI SDK surface: model calls, tools, MCP,
structured output, media, and provider adapters. Realtime sessions support
xAI's turn-based adapter and continuous server-WebSocket sessions for OpenAI
Live, Google Gemini Live, and Gateway; browser WebRTC flows and other
provider-specific realtime families are not supported yet. Web framework hooks
and React Server Components are out of scope. Apps use the Swift-native
[chat session](https://swiftaisdk.github.io/SwiftAISDK/core/chat/) and [agents](https://swiftaisdk.github.io/SwiftAISDK/core/agents/) instead.
