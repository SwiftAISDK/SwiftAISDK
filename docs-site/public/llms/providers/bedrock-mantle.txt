# Amazon Bedrock Mantle

Source URL: https://swiftaisdk.github.io/SwiftAISDK/providers/bedrock-mantle/

OpenAI-compatible Chat Completions and Responses endpoints on Amazon Bedrock Mantle, authenticated with a Bedrock API key or SigV4 credentials. The endpoint path is chosen from the model ID.

Provider ID: `bedrock-mantle` · Upstream package: `@ai-sdk/amazon-bedrock`

## Package

The complete `SwiftAISDK` umbrella (`import SwiftAISDK`) already includes this provider.
For a smaller dependency graph, add only core and `swift-ai-amazon-bedrock`:

```swift
// Package.swift
.package(url: "https://github.com/SwiftAISDK/swift-ai-core.git", from: "1.5.0"),
.package(url: "https://github.com/SwiftAISDK/swift-ai-amazon-bedrock.git", from: "1.1.3"),

// Target dependencies
.product(name: "SwiftAI", package: "swift-ai-core"),
.product(name: "SwiftAIAmazonBedrock", package: "swift-ai-amazon-bedrock"),
```

```swift
import SwiftAI
import SwiftAIAmazonBedrock
```

Versions shown are from the tested 3.4.0 release set. See [Install](https://swiftaisdk.github.io/SwiftAISDK/getting-started/install/) for credentials and native factory settings.

## Credentials

The default factory reads these environment variables. Explicit provider settings take precedence.

| Variable | Purpose |
| --- | --- |
| `AWS_BEARER_TOKEN_BEDROCK` | Bedrock API key used as a bearer token. Takes precedence over SigV4 credentials, including a `credentialProvider`. |
| `AWS_ACCESS_KEY_ID` | Access key for SigV4 signing when no bearer token or credential provider is configured. |
| `AWS_SECRET_ACCESS_KEY` | Secret key for SigV4 signing when no bearer token or credential provider is configured. |
| `AWS_SESSION_TOKEN` | Optional session token for temporary credentials. |
| `AWS_REGION` | AWS region used in the `bedrock-mantle.\<region\>.api.aws` host. Defaults to `us-east-1`. |
| `AWS_DEFAULT_REGION` | Fallback region, read when `AWS_REGION` is not set. |

`AIProviders.bedrockMantle`

## Capabilities

- [Language](https://swiftaisdk.github.io/SwiftAISDK/core/generate-text/)

## Quick start

```swift
import SwiftAISDK

let provider = try AIProviders.bedrockMantle(settings: AmazonBedrockProviderSettings(
    region: "us-east-1"
))
let model = try provider.languageModel("openai.gpt-oss-120b")
let result = try await model.generateText("Explain Bedrock Mantle in one sentence.")
print(result.text)
```

With modular packages, `import SwiftAI` and `import SwiftAIAmazonBedrock`, then call
`AIProviders.bedrockMantle(configuration: AmazonBedrockProviderSettings(...))`;
the native factory requires the configuration argument.

Bedrock Mantle exposes OpenAI-compatible endpoints at
`https://bedrock-mantle.<region>.api.aws`.

## Chat and Responses

- `languageModel(...)` and `chat(...)` use Chat Completions.
- `responses(...)` uses the Responses API.

```swift
let responses = try provider.responses("openai.gpt-oss-120b")
let answer = try await responses.generateText("List three uses for embeddings.")
```

The path is chosen from the model ID: OpenAI GPT models other than GPT-OSS
(`openai.gpt-...`), Gemma 4 (`google.gemma-4...`) and xAI (`xai....`) models use
`/openai/v1`; other models, including `openai.gpt-oss-...`, use `/v1`. A custom
`baseURL` replaces both. The Responses model does not request web-search source
lists, because Mantle does not accept that include.

Request options and results follow the [OpenAI-compatible](https://swiftaisdk.github.io/SwiftAISDK/providers/openai-compatible/)
Chat and Responses adapters.

## Credentials and region

Authentication matches [Amazon Bedrock](https://swiftaisdk.github.io/SwiftAISDK/providers/amazon-bedrock/#authentication):
`apiKeyProvider`, then `apiKey` or `AWS_BEARER_TOKEN_BEDROCK`, then
`credentialProvider`, then access keys from settings or `AWS_ACCESS_KEY_ID` /
`AWS_SECRET_ACCESS_KEY` with optional `AWS_SESSION_TOKEN`. SigV4 requests are
signed for the `bedrock-mantle` service. The region comes from `region`,
`AWS_REGION` or `AWS_DEFAULT_REGION` and defaults to `us-east-1`; the
`AWS_ENDPOINT_URL*` variables are not used, so set `baseURL` to change the host.
