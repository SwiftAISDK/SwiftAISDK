# Claude Platform on AWS

Source URL: https://swiftaisdk.github.io/SwiftAISDK/providers/anthropic-aws/

Claude models through Anthropic's Claude Platform on AWS, authenticated with an Anthropic AWS API key or AWS SigV4 credentials and scoped to a workspace. It uses the same Messages adapter as the Anthropic provider, including message threads, files and skills.

Provider ID: `anthropic-aws` · Upstream package: `@ai-sdk/anthropic-aws`

## Package

The complete `SwiftAISDK` umbrella (`import SwiftAISDK`) already includes this provider.
For a smaller dependency graph, add only core and `swift-ai-anthropic-aws`:

```swift
// Package.swift
.package(url: "https://github.com/SwiftAISDK/swift-ai-core.git", from: "1.5.0"),
.package(url: "https://github.com/SwiftAISDK/swift-ai-anthropic-aws.git", from: "1.2.2"),

// Target dependencies
.product(name: "SwiftAI", package: "swift-ai-core"),
.product(name: "SwiftAIAnthropicAWS", package: "swift-ai-anthropic-aws"),
```

```swift
import SwiftAI
import SwiftAIAnthropicAWS
```

Versions shown are from the tested 3.4.0 release set. See [Install](https://swiftaisdk.github.io/SwiftAISDK/getting-started/install/) for credentials and native factory settings.

## Credentials

The default factory reads these environment variables. Explicit provider settings take precedence.

| Variable | Purpose |
| --- | --- |
| `ANTHROPIC_AWS_WORKSPACE_ID` | Workspace ID sent as `anthropic-workspace-id`. Required unless `workspaceID` is set in settings. |
| `AWS_REGION` | AWS region used for the endpoint host and SigV4 signing. Required unless `region` or `baseURL` is set. |
| `AWS_DEFAULT_REGION` | Fallback region, read when `AWS_REGION` is not set. |
| `ANTHROPIC_AWS_API_KEY` | API key sent as `x-api-key`. When present, it is used instead of SigV4 signing. |
| `AWS_ACCESS_KEY_ID` | Access key for SigV4 signing when no API key or credential provider is configured. |
| `AWS_SECRET_ACCESS_KEY` | Secret key for SigV4 signing when no API key or credential provider is configured. |
| `AWS_SESSION_TOKEN` | Optional session token for temporary SigV4 credentials. |

## Quick start

```swift
import SwiftAISDK

let provider = try AIProviders.anthropicAWS(settings: AnthropicAWSProviderSettings(
    region: "us-east-1",
    workspaceID: "your-workspace-id"
))
let model = try provider.languageModel("claude-sonnet-4-6")
let result = try await model.generateText("Say hello from Claude Platform on AWS.")
print(result.text)
```

`AIProviders.anthropicAWS()` with no arguments reads the region and workspace from
the environment. With modular packages, `import SwiftAI` and
`import SwiftAIAnthropicAWS`, then call
`AIProviders.anthropicAWS(configuration: AnthropicAWSProviderSettings(...))`; the
native factory requires the configuration argument.

Requests go to `https://aws-external-anthropic.<region>.api.aws/v1` and carry an
`anthropic-workspace-id` header. A workspace ID is always required; a region is
required unless you set `baseURL`. The region must be a single DNS label.
`messages(...)` is an alias for `languageModel(...)`.

## Authentication

The provider picks the first available method:

1. `apiKeyProvider`: an async throwing closure called before each request. It must
return a non-empty key; errors and blank values stop the request before it is
sent.
2. `apiKey`, or `ANTHROPIC_AWS_API_KEY`, sent as `x-api-key`.
3. AWS SigV4 signing (service `aws-external-anthropic`) with `credentialProvider`,
or with `accessKeyID`/`secretAccessKey`/`sessionToken`, or with
`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` and `AWS_SESSION_TOKEN`.

```swift
let provider = try AIProviders.anthropicAWS(settings: AnthropicAWSProviderSettings(
    region: "us-east-1",
    workspaceID: "your-workspace-id",
    credentialProvider: {
        // Your own credential source, for example an STS AssumeRole call.
        let credentials = try await loadTemporaryAWSCredentials()
        return AnthropicAWSCredentials(
            accessKeyID: credentials.accessKeyID,
            secretAccessKey: credentials.secretAccessKey,
            sessionToken: credentials.sessionToken
        )
    }
))
```

The provider does not run the AWS SDK credential chain; supply credentials through
settings, a `credentialProvider` closure, or the environment variables above.
Header values with non-ASCII characters are sent but excluded from the signature.

## Messages features

The provider uses the same Messages adapter as [Anthropic](https://swiftaisdk.github.io/SwiftAISDK/providers/anthropic/), so
`providerOptions["anthropic"]` (thinking, effort, cache control, structured output
mode and the rest), `AnthropicTools`, citations and streaming behave as described
there.

Message threads are enabled: pass `providerOptions["anthropic"]["thread"]` with
`["type": "create"]` or `["type": "continue", "previousMessageId": "msg_..."]`,
and keep the full history locally for recovery when a thread expires.

`provider.files()` and `provider.skills()` return Files and Skills clients for the
workspace. Message batches are only available on the direct Anthropic provider.
