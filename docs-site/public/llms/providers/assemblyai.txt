# AssemblyAI

Source URL: https://swiftaisdk.github.io/SwiftAISDK/providers/assemblyai/

AssemblyAI file transcription with timed words and automatic language detection, plus buffered Speech V4 for MP3 and PCM output.

Provider ID: `assemblyai` · Upstream package: `@ai-sdk/assemblyai`

## Package

The complete `SwiftAISDK` umbrella (`import SwiftAISDK`) already includes this provider.
For a smaller dependency graph, add only core and `swift-ai-assemblyai`:

```swift
// Package.swift
.package(url: "https://github.com/SwiftAISDK/swift-ai-core.git", from: "1.6.0"),
.package(url: "https://github.com/SwiftAISDK/swift-ai-assemblyai.git", from: "1.2.0"),

// Target dependencies
.product(name: "SwiftAI", package: "swift-ai-core"),
.product(name: "SwiftAIAssemblyAI", package: "swift-ai-assemblyai"),
```

```swift
import SwiftAI
import SwiftAIAssemblyAI
```

Versions shown are from the tested 3.6.0 release set. See [Install](https://swiftaisdk.github.io/SwiftAISDK/getting-started/install/) for credentials and native factory settings.

## Quick start

```swift
import Foundation
import SwiftAISDK

let provider = try AIProviders.assemblyAI()
let model = try provider.transcriptionModel("assemblyai-stt-3-7")
let audio = try Data(contentsOf: URL(fileURLWithPath: "meeting.mp3"))
let result = try await model.transcribe(audio: audio, fileName: "meeting.mp3", mimeType: "audio/mpeg")
print(result.text)
```

With modular packages, `import SwiftAI` and `import SwiftAIAssemblyAI`, then call
`AIProviders.assemblyAI(configuration: AssemblyAIProviderSettings(...))`; the
native factory requires the configuration argument.

Each call uploads the audio to `/v2/upload`, submits a transcript job and polls it
every 3 seconds. Polling gives up after 60 seconds, so very long recordings may
time out. See [Transcribe](https://swiftaisdk.github.io/SwiftAISDK/core/transcribe/).

## Transcription models

- `assemblyai-stt-3-7` is the flagship model. It supports prompting, keyterms,
temperature and removal of inline audio tags.
- `universal-2` is available for languages beyond the flagship model's coverage.
It returns an informational warning recommending the flagship when available.
- `universal-3-5-pro` is deprecated and returns a migration warning pointing to
`assemblyai-stt-3-7`.

The provider sends every model ID in `speech_models`. If you used `best`,
`slam-1`, `nano` or `universal-3-pro`, switch to `assemblyai-stt-3-7` or
`universal-2` according to your language needs.

## Transcription options

Pass options under `providerOptions["assemblyai"]`; types and ranges are validated
before upload.

```swift
let result = try await model.transcribe(
    audio: audio,
    fileName: "meeting.mp3",
    mimeType: "audio/mpeg",
    providerOptions: [
        "assemblyai": [
            "speakerLabels": true,
            "keytermsPrompt": ["SwiftAISDK", "Bedrock"],
            "sentimentAnalysis": true,
        ],
    ]
)
```

Supported keys include:

- Audio range and speakers: `audioStartFrom`, `audioEndAt` (milliseconds),
`speakerLabels`, `speakersExpected`, `speakerOptions`, `multichannel`.
- Language: `languageCode` (or the shared `language` argument),
`languageDetection`, `languageDetectionOptions`, `languageConfidenceThreshold`.
- Prompting: `prompt`, `keytermsPrompt`, `customSpelling`, `domain`,
`temperature` (0–1), `speechThreshold` (0–1), `removeAudioTags` (`all` or
`speaker`).
- Formatting: `punctuate`, `formatText`, `disfluencies`, `filterProfanity`.
- Audio intelligence: `autoChapters`, `autoHighlights`, `contentSafety`,
`contentSafetyConfidence` (25–100), `entityDetection`, `iabCategories`,
`sentimentAnalysis`, `summarization`, `summaryModel`, `summaryType`.
- PII redaction: `redactPii`, `redactPiiPolicies`, `redactPiiSub`,
`redactPiiAudio`, `redactPiiAudioQuality`, `redactPiiAudioOptions`,
`redactPiiReturnUnredacted`, `redactStaticEntities`.
- Webhooks: `webhookUrl`, `webhookAuthHeaderName`, `webhookAuthHeaderValue`.

Use `keytermsPrompt` for vocabulary boosts with `assemblyai-stt-3-7`. The
`wordBoost` and `boostParam` options are deprecated. Choose automatic language
detection or an explicit language code. Enable `redactPii` or `redactPiiAudio`
when setting their dependent options.

## Transcription results

Word timestamps are converted from milliseconds to seconds in `segments`.
Audio-intelligence output is returned under `providerMetadata["assemblyai"]`:
`utterances`, `sentimentAnalysisResults`, `entities`, `contentSafetyLabels`,
`iabCategoriesResult` and `autoHighlightsResult`. A transcript that finishes with
status `error` throws `AIError.invalidResponse` with AssemblyAI's message.

## Speech generation

Use `assemblyai-tts-1` to synthesize speech. The provider sends a buffered
request to `https://tts.us.assemblyai.com/v1/speech` and returns the complete
audio in `SpeechResult.audio`. See [Generate speech](https://swiftaisdk.github.io/SwiftAISDK/core/generate-speech/).

```swift
let model = try provider.speechModel("assemblyai-tts-1")
let options = AssemblyAISpeechModelOptions(
    encoding: .pcmS16LE,
    container: .wav,
    sampleRate: 16000
)
let result = try await AI.generateSpeech(
    model: model,
    request: SpeechRequest(
        text: "Hello, world!",
        voice: "aai-kyla",
        language: "en",
        providerOptions: options.providerOptions
    )
)
```

The native `AssemblyAIProvider` also exposes `speech(_:)`, which returns an
`AssemblyAISpeechModel`. Set `speechBaseURL` on `AssemblyAIProviderSettings` to
override the TTS origin independently of the transcription `baseURL`.

- Pass a voice slug such as `aai-kyla` or a voice ID. The provider accepts `de`,
`en`, `es`, `fr`, `it`, and `pt` as language codes and accepts their full
language names. Omit `language` to use the voice's own language.
- Set `format` to `mp3` (default), `wav`, `pcm` (raw 16-bit PCM), `mulaw`, or
`alaw`. The two G.711 formats default to raw 8 kHz audio. Unknown formats
fall back to MP3 with a warning.
- `AssemblyAISpeechModelOptions` and `providerOptions["assemblyai"]` accept
`encoding`, `container`, `sampleRate`, and `bitRate`. Encoding overrides
`format`. Use `raw` or `wav` containers with PCM encodings, sample rates of
8000, 16000, 22050, 24000, 44100, or 48000 Hz, and MP3 bit rates of 32000,
48000, 64000, 96000, or 128000 bits per second.
- Automatic language detection, unsupported language choices, nondefault speed,
and instructions produce warnings. The SDK omits those options from the request.

When AssemblyAI returns its billing header, `result.usage?["characters"]`
reports the billed character count. `result.providerMetadata["assemblyai"]`
contains the available request ID, model, voice ID, language, encoding, sample
rate, audio duration in milliseconds and billed characters. HTTP failures expose
the provider's message in `AIError.apiCallError?.message` and preserve the wire
body in `responseBody`.

## Rotating credentials

`AssemblyAIProviderSettings` accepts an `apiKeyProvider` async throwing closure
that is called before each authenticated request, including speech generation,
audio upload, transcript submission and every poll. A supplier error stops the
request before it is sent.
