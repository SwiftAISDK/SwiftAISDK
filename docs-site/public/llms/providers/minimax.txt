# MiniMax

Source URL: https://swiftaisdk.github.io/SwiftAISDK/providers/minimax/

MiniMax M-series language models through an Anthropic-compatible Messages API, plus H3 image generation and editing and H3 video generation. M3.1 and later models add reasoning effort, image and video input, and prompt caching.

Provider ID: `minimax` · Upstream package: `@ai-sdk/minimax`

## Package

The complete `SwiftAISDK` umbrella (`import SwiftAISDK`) already includes this provider.
For a smaller dependency graph, add only core and `swift-ai-minimax`:

```swift
// Package.swift
.package(url: "https://github.com/SwiftAISDK/swift-ai-core.git", from: "1.5.0"),
.package(url: "https://github.com/SwiftAISDK/swift-ai-minimax.git", from: "1.3.1"),

// Target dependencies
.product(name: "SwiftAI", package: "swift-ai-core"),
.product(name: "SwiftAIMiniMax", package: "swift-ai-minimax"),
```

```swift
import SwiftAI
import SwiftAIMiniMax
```

Versions shown are from the tested 3.5.0 release set. See [Install](https://swiftaisdk.github.io/SwiftAISDK/getting-started/install/) for credentials and native factory settings.

## Quick start

```swift
import SwiftAISDK

let provider = try AIProviders.miniMax() // reads MINIMAX_API_KEY
let model = try provider.languageModel("minimax-m3.1-flash")
let result = try await model.generateText("Give me three names for a Swift package.")
print(result.text)
```

With modular packages, `import SwiftAI` and `import SwiftAIMiniMax`, then call
`AIProviders.miniMax(configuration: MiniMaxProviderSettings(...))`. The native
factory requires the `configuration` argument. Both factories return
`MiniMaxProvider`.

## Endpoints and credentials

The language model uses MiniMax's Anthropic-compatible Messages API at
`https://api.minimax.io/anthropic/v1`, with the key in `x-api-key`. Video
(`https://api.minimax.io`) and image (`https://api.minimax.io/v1`) requests send
it as a bearer token. Override each host with `baseURL`, `videoBaseURL` or
`imageBaseURL`. Set `environment` to read `MINIMAX_API_KEY` from a dictionary
instead of the process environment.

`MiniMaxProviderSettings.apiKeyProvider` is an async throwing closure called before
each Messages, video or image request; creating a model does not call it.

## Language models

Messages requests reuse the [Anthropic](https://swiftaisdk.github.io/SwiftAISDK/providers/anthropic/) request builder, so
thinking blocks, citations and the `anthropic` provider options work. The
`minimax` namespace takes precedence over `anthropic`.

### Reasoning and sampling (M3.1 and later)

`minimax-m3.1-flash` and later M-series versions (compared by version number, so
M3.10 and M4 qualify) support explicit reasoning effort, image and video input,
and cache markers. M3.0, older models and unrecognized IDs keep the plain
Anthropic-compatible behavior.

```swift
let result = try await model.generateText(
    "Plan a three-day trip to Kyoto.",
    options: LanguageGenerationOptions(
        providerOptions: MiniMaxLanguageModelOptions(effort: .high, serviceTier: .priority).providerOptions
    )
)
```

- Portable `reasoning` accepts `low`, `medium`, `high`, `xhigh` and `max`. These
models always reason, so `none` and `minimal` map to `low` with a warning. An
explicit `minimax.effort` or `anthropic.effort` wins; omit `reasoning` or use
`provider-default` to keep the server default.
- `thinking` accepts `.adaptive` or `.disabled`.
- `serviceTier` (`.standard` or `.priority`) is sent as `service_tier`. Other tier
values warn and are omitted.
- Temperature accepts 0–2, and top-p stays available with adaptive thinking.
Top-k is removed with a warning.
- When effort is mapped, usage metadata appears under both `anthropic` and
`minimax`.

### Images and video in chat

M3.1 and later accept image URLs, inline image data, hosted video URLs and
uploaded MiniMax video IDs:

```swift
let result = try await model.generateText(messages: [
    AIMessage(role: .user, content: [
        .text("Describe what changes between these scenes."),
        .imageURL(
            "https://example.com/scene.png",
            providerMetadata: MiniMaxImagePartOptions(detail: .high).providerOptions
        ),
        .videoURL(
            "https://example.com/clip.mp4",
            providerMetadata: MiniMaxVideoPartOptions(fps: 1).providerOptions
        ),
        .providerReference(mimeType: "video/mp4", reference: ["minimax": "uploaded-video-id"]),
    ]),
])
```

Image `detail` is `low`, `default` or `high`. Video `fps` must be between 0.2 and
5. Uploaded video IDs get the `mm_file://` prefix once. Image file references are
not supported, and this provider has no file-upload client. PDFs use the shared
Anthropic document conversion.

### Prompt caching

Attach `MiniMaxCacheControlOptions(cacheControl: .ephemeral).providerOptions` as
message or content-part `providerMetadata`. A message marker applies to its last
block. Up to four breakpoints are kept across prompt blocks and tools, and each
extra marker produces a warning.

## Images

```swift
let image = try provider.image("MiniMax-H3-Image")
let result = try await image.generateImage(
    "A red circle on white paper",
    aspectRatio: "1:1",
    count: 2,
    providerOptions: MiniMaxImageModelOptions(area: .twoK, outputFormat: .png).providerOptions
)
```

`MiniMax-H3-Image` and `MiniMax-H3-Image-Highspeed` support text-to-image and
reference-image editing (`files`) through `/images/generations` and `/images/edits`.
Up to 10 images per call. Images are downloaded and returned as base64; the
download does not include your key or headers. If some images in a batch fail, the
rest are returned and each failure becomes a warning. `seed` is not supported,
masks throw, and `outputCompression` accepts 0–100.

## Video

`videoModel("MiniMax-H3")` (or `MiniMax-H3-Max`) supports text-to-video,
first and last frames, reference images and reference audio. H3-Max does not
accept references.

- Resolution: H3 supports `768P` and `2K` (default `2K`); H3-Max supports `480P`
and `768P` (default `768P`).
- Duration defaults to 5 seconds and is rounded to whole seconds. Values are
clamped to 4–15 seconds for H3 and 5–15 for other models, with a warning.
- Text-to-video defaults to `16:9`.
- `providerOptions["minimax"]` accepts `resolution`, `ratio`, `referenceAudioUrls`,
`aigcWatermark`, `pollIntervalMs` and `pollTimeoutMs`.

Video jobs also support `startVideoGeneration` and `videoGenerationStatus`; save
the returned operation to resume status checks later. See
[Generate video](https://swiftaisdk.github.io/SwiftAISDK/core/generate-video/).
