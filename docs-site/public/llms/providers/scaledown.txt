# ScaleDown

Source URL: https://swiftaisdk.github.io/SwiftAISDK/providers/scaledown/

ScaleDown classification decisions (Choice, Boolean and Score) and text extraction over text, JSON and one JPEG, PNG, TIFF or PDF document. Extraction supports text fields and lists of text only.

Provider ID: `scaledown` · Upstream package: `@ai-sdk/scaledown`

## Package

The complete `SwiftAISDK` umbrella (`import SwiftAISDK`) already includes this provider.
For a smaller dependency graph, add only core and `swift-ai-scaledown`:

```swift
// Package.swift
.package(url: "https://github.com/SwiftAISDK/swift-ai-core.git", from: "1.5.0"),
.package(url: "https://github.com/SwiftAISDK/swift-ai-scaledown.git", from: "1.0.0"),

// Target dependencies
.product(name: "SwiftAI", package: "swift-ai-core"),
.product(name: "SwiftAIScaleDown", package: "swift-ai-scaledown"),
```

```swift
import SwiftAI
import SwiftAIScaleDown
```

Versions shown are from the tested 3.4.0 release set. See [Install](https://swiftaisdk.github.io/SwiftAISDK/getting-started/install/) for credentials and native factory settings.

## Quick start

```swift
import SwiftAISDK

let scaleDown = AIProviders.scaleDown()
let result = try await AI.experimentalDecide(
    model: try scaleDown.decisionModel("classify-1"),
    state: .text("The export crashes in Safari."),
    questions: [
        "category": .choice(criteria: ["bug": "Broken functionality", "feedback": nil]),
        "workaround": .boolean(instructions: "Is there a workaround?"),
        "severity": .score(criteria: ["Cosmetic", "Degraded", "Blocking"])
    ]
)
print(result.answers)
```

For the modular packages, use `import SwiftAI` and `import SwiftAIScaleDown`, then
`AIProviders.scaleDown(configuration: ScaleDownProviderSettings(...))` or
`createScaleDown(configuration:)`. Both default to `ScaleDownProviderSettings()` and do
not throw; `scaledown` and `scaleDown` are the same default provider instance.

ScaleDown provides decision and extraction models only; there is no batching or
streaming.

## Decisions

Decisions use `/v1/scaledown`. `classify` and `classify-1` are the known model IDs;
custom IDs are forwarded. Choice, Boolean and Score questions are supported; Box
questions are rejected before the request.

- A Choice option with a nil description uses the option ID as its description.
- Structured instructions and criteria are sent as compact JSON text; Boolean criteria
become explicit yes/no instructions.
- Score rubrics need 2–10 non-null levels.

Results keep probabilities and token usage. `providerMetadata["scaledown"]` holds
confidence, the score legend and the request cost when reported. `maxOutputTokens`,
`reasoning` and decision provider options produce warnings. See
[Decisions](https://swiftaisdk.github.io/SwiftAISDK/core/decide/).

## Extraction

```swift
let extraction = try await AI.experimentalExtract(
    model: try scaleDown.extractionModel("extract-1"),
    state: .text("Acme Corp. Contacts: Ana, Bo."),
    fields: [
        "vendor": .init(type: .text, instructions: "Company name"),
        "contacts": .init(type: .list, instructions: "Contact names", items: .text)
    ],
    providerOptions: ScaleDownExtractionModelOptions(threshold: 0.5).providerOptions
)
```

Extraction uses `/v1/chat/completions` with `extract`, `extract-1` or custom IDs. Only
text fields and lists of text are supported; number, date, time, datetime, duration
and non-text list fields are rejected before the request. `threshold` must be between
0 and 1.

- Scalar fields take the highest-confidence entity (the first on ties); lists keep
entity order. Empty or missing values become `nil`.
- Text sources are returned only when ScaleDown's UTF-8 byte span matches the original
text exactly; they are converted to Swift string offsets. JSON evidence is never cited.
- OCR matches cite the file part, and the OCR text is exposed as
`providerMetadata["scaledown"]["ocrText"]`.
- `referenceDate`, `maxOutputTokens` and `reasoning` produce warnings.

If the extraction content is malformed, `ScaleDownInvalidExtractionContentError` keeps
the raw string in `data`. See [Extract](https://swiftaisdk.github.io/SwiftAISDK/core/extract/).

## Documents

Both models accept ordered text and JSON parts plus at most one inline JPEG, PNG, TIFF or
PDF file, for example `.file(mediaType: "application/pdf", data: .data(bytes))` or
`.base64(value)`. Provider file references and URLs are rejected by the provider;
`AI.experimentalDecide` and `AI.experimentalExtract` download URLs before calling it.
File-only extraction sends a default user message.

## Authentication and errors

Requests send the key as `x-api-key`. It is resolved for each request: `apiKeyProvider`
(an async throwing closure) first, then `apiKey`, then `SCALEDOWN_API_KEY`. Pass
`environment: [:]` for an isolated environment. The default base URL is
`https://api.scaledown.xyz`; `baseURL`, `headers` and `transport` are configurable, and
call headers override provider headers.

HTTP errors keep the status, raw body, headers and retryability in `AIError.apiCall`;
a `detail` string or validation-detail list becomes the error message.
