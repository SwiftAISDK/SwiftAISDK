# xAI (Grok)

Source URL: https://swiftaisdk.github.io/SwiftAISDK/providers/xai/

xAI Grok language models over the Responses API with hosted web, X and code tools, plus Grok Imagine image and video generation, speech, batch and streaming transcription, files, batch text and realtime voice sessions.

Provider ID: `xai` · Upstream package: `@ai-sdk/xai`

## Package

The complete `SwiftAISDK` umbrella (`import SwiftAISDK`) already includes this provider.
For a smaller dependency graph, add only core and `swift-ai-xai`:

```swift
// Package.swift
.package(url: "https://github.com/SwiftAISDK/swift-ai-core.git", from: "1.5.0"),
.package(url: "https://github.com/SwiftAISDK/swift-ai-xai.git", from: "1.2.2"),

// Target dependencies
.product(name: "SwiftAI", package: "swift-ai-core"),
.product(name: "SwiftAIXAI", package: "swift-ai-xai"),
```

```swift
import SwiftAI
import SwiftAIXAI
```

Versions shown are from the tested 3.5.0 release set. See [Install](https://swiftaisdk.github.io/SwiftAISDK/getting-started/install/) for credentials and native factory settings.

## Quick start

```swift
import SwiftAISDK

let xai = try AIProviders.xAI()
let model = try xai.languageModel("grok-4.7")
let result = try await model.generateText("Explain Swift's Sendable in one paragraph.")
print(result.text)
```

For the modular packages, use `import SwiftAI` and `import SwiftAIXAI`, then
`try AIProviders.xAI(configuration: XAIProviderSettings(...))`. The native factory
requires a configuration argument; `XAIProviderSettings()` reads `XAI_API_KEY`.

## Responses and chat

`languageModel(_:)`, `responses(_:)` and the callable provider use the xAI Responses
API; new code should use them. `chatModel(_:)` keeps the legacy Chat Completions
dialect for existing code. Responses models also back
[batch text generation](https://swiftaisdk.github.io/SwiftAISDK/core/batch-text/) through `experimentalBatch()`.

Responses options go under `providerOptions["xai"]`:

| Option | Behavior |
| --- | --- |
| `reasoningEffort` | `none`, `low`, `medium`, `high` or `xhigh`; passed through unchanged. |
| `reasoningSummary` | `auto`, `concise` or `detailed`. |
| `serviceTier` | `default` or `priority`. |
| `logprobs`, `topLogprobs` | Boolean; integer 0–8. |
| `minP`, `maxTurns` | 0–1; integer. |
| `parallelToolCalls`, `store`, `previousResponseId` | Tool parallelism, storage and continuation. |
| `promptCacheKey`, `safetyIdentifier`, `user` | Strings. |
| `include` | `file_search_call.results`, `web_search_call.action.sources`, `code_interpreter_call.outputs`, `reasoning.encrypted_content`, `no_inline_citations`. |

Streams emit each citation source once, even when xAI repeats incremental annotations
in the final output item.

## Reasoning

Portable `reasoning` maps to xAI effort levels. Grok 4.5–4.9 and Grok 5-family models
cannot disable reasoning, so `none` maps to `low` with a compatibility warning; older
families keep `none`. Exactly `grok-4.6` maps `xhigh` and `max` to `xhigh`; other models,
including `grok-4.7`, map them to `high`. Models without effort control warn instead.

## Server-side tools

`XAITools` creates hosted tools: `webSearch(allowedDomains:excludedDomains:...)`,
`xSearch(allowedXHandles:excludedXHandles:fromDate:toDate:...)` (at most 20 handles per
list), `codeExecution()`, `viewImage()`, `viewXVideo()`, `imageGeneration(action:)`,
`fileSearch(vectorStoreIDs:maxNumResults:)` and `mcpServer(serverURL:...)`.

```swift
let answer = try await model.generateText(
    "What are people saying about Swift 6.3?",
    tools: LanguageToolOptions(rawTools: ["x_search": XAITools.xSearch()])
)
```

## Images

```swift
let image = try xai.imageModel("grok-imagine-image")
let result = try await image.generateImage("A neon city at night", aspectRatio: "16:9")
```

Calls with `files` use the edit endpoint; `grok-imagine-image`, `grok-imagine-image-pro`
and `grok-imagine-image-2.0` accept input files. Masks are not supported. At most three
images are returned per call. `providerOptions["xai"]` accepts `resolution` (`1k`,
`1.5k`, `2k`), `quality` (`low`, `medium`, `high`, `auto`), `outputFormat`, `syncMode`
and `user`. Moderated results throw. Revised prompts and cost are under
`providerMetadata["xai"]`.

## Videos

```swift
let video = try xai.videoModel("grok-imagine-video-1.5")
let clip = try await video.generateVideo("A paper plane over a canyon", aspectRatio: "16:9", durationSeconds: 6)
```

The mode follows the request: text or image to video by default,
`reference-to-video` when `inputReferences` contain images or audio (even alongside
frame images) or `referenceImageUrls` is set, and `edit-video` or
`extend-video` with `providerOptions["xai"]["videoUrl"]` or an explicit `mode`. Other
options under `providerOptions["xai"]`:

- `resolution`: `480p`, `720p` or `1080p` (`1920x1080`, `1280x720`, `854x480` and
`640x480` are also mapped from the shared `resolution`).
- `referenceImageUrls` (1–7) and `referenceVoiceIds` (at most 3).
- `keyframes` (`imageUrl` and `timestampSeconds`, `grok-imagine-video-1.5` only) and
`storageOptions`.
- `output.uploadUrl`: an HTTPS URL for direct delivery to your storage. The result then
lists `uploadedVideos` even without a download URL, and the signed URL is removed from
returned metadata.
- `pollIntervalMs` and `pollTimeoutMs`: defaults 5000 and 600000.

## Speech

```swift
let speech = try xai.speechModel()
let audio = try await speech.generateSpeech("Hello from Grok.", voice: "eve", format: "mp3")
```

Speech uses `/tts`. The voice defaults to `eve` and the language to `auto`. Formats are
`mp3`, `wav`, `pcm`, `mulaw` and `alaw`; others fall back to `mp3` with a warning.
`instructions` is not supported; use xAI speech tags in the text. `providerOptions["xai"]`
accepts `sampleRate`, `bitRate` (mp3 only), `optimizeStreamingLatency` (0–2),
`textNormalization`, `withTimestamps` and `replace` pronunciation rules. Trace ID,
duration and timestamps are under `providerMetadata["xai"]`.

## Transcription

`transcriptionModel()` uses `/stt` for batch transcription and returns word timings; it
warns when segment timings are requested. `streamingTranscriptionModel(_:webSocketTransport:)`
streams audio over a WebSocket with `audioFormat` (`pcm`, `mulaw`, `alaw`, `opus`),
`sampleRate`, VAD, interim/final results and multichannel input. Options include
`language`, `format`, `multichannel`, `channels`, `diarize` and `fillerWords`. See
[Transcribe audio](https://swiftaisdk.github.io/SwiftAISDK/core/transcribe/).

## Files and realtime

`files()` uploads, inspects, downloads and deletes xAI files for use as provider
references; see [Files](https://swiftaisdk.github.io/SwiftAISDK/core/files/). `realtimeModel(_:)`, for example
`grok-voice-latest`, creates realtime sessions with ephemeral client secrets; see
[Realtime](https://swiftaisdk.github.io/SwiftAISDK/core/realtime/). Server connections derive their WebSocket URL from
the configured base URL.

## Rotating credentials

`XAIProviderSettings.apiKeyProvider` accepts an async throwing closure. It is resolved
before each native language, files, batch, image, speech, transcription, video polling
and realtime client-secret request, and before each streaming-transcription WebSocket
connection. Explicit authorization headers keep precedence, and a supplier failure stops
the request before it is sent.
