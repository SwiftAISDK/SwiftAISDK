# Generate audio

Source URL: https://swiftaisdk.github.io/SwiftAISDK/core/generate-audio/

Use `AI.generateAudio` to turn a text prompt into audio that is not spoken
text: music cues, sound effects or ambience. For text-to-speech, use
[Generate speech](https://swiftaisdk.github.io/SwiftAISDK/core/generate-speech/) instead.

```swift title="Examples/Sources/GenerateAudio/main.swift"
import Foundation
import SwiftAISDK

@main
struct GenerateAudioExample {
    static func main() async {
        do {
            let provider = try AIProviders.elevenLabs()

            let soundEffects = try provider.soundEffectsModel()
            let click = try await AI.generateAudio(
                "A single soft interface click.",
                using: soundEffects,
                durationSeconds: 0.5,
                format: "mp3_32",
                providerOptions: ["elevenlabs": ["promptInfluence": 0.3]]
            )
            print("Generated sound effect bytes: \(click.audio.count)")

            let music = try provider.musicModel()
            let cue = try await AI.generateAudio(
                "Three seconds of quiet instrumental piano, no vocals.",
                using: music,
                durationSeconds: 3,
                format: "mp3_32",
                providerOptions: ["elevenlabs": ["forceInstrumental": true]]
            )
            print("Generated music bytes: \(cue.audio.count)")
        } catch {
            print("Audio generation failed: \(error)")
        }
    }
}
```

The example makes two provider requests and needs `ELEVENLABS_API_KEY`.

## Providers

[ElevenLabs](https://swiftaisdk.github.io/SwiftAISDK/providers/elevenlabs/) is the provider that implements
`AudioGenerationModel`:

| Model factory | Default model ID | Endpoint |
| --- | --- | --- |
| `provider.musicModel()` / `music()` | `music_v1` | `/v1/music` (`/v1/music/detailed` with timestamps) |
| `provider.soundEffectsModel()` / `soundEffects()` | `eleven_text_to_sound_v2` | `/v1/sound-generation` |

Pass a model ID to either factory to select another model. Calling these
factories on a provider other than ElevenLabs throws
`AIError.unsupportedModel` with the `.audioGeneration` capability.

## Options

`AI.generateAudio(_:using:...)` builds an `AudioGenerationRequest`; you can also
pass one to `AI.generateAudio(model:request:)`.

- `prompt`: the natural-language audio prompt.
- `durationSeconds`: requested length. Music sends it as milliseconds; sound
effects send it in seconds. The adapter forwards the value without range
validation, so out-of-range lengths are rejected by ElevenLabs.
- `format`: output format. Short aliases such as `mp3`, `mp3_32`, `pcm`, `ulaw`
and `wav` map to native names (`mp3_44100_32`, `pcm_44100`…); native names
such as `mp3_44100_128` pass through. When omitted, the provider default
applies.
- `seed`: deterministic generation when the model supports it.
- `providerOptions`: provider controls under the `"elevenlabs"` key.
- `extraBody`, `headers`, `abortSignal`, `retryPolicy` and `telemetry` follow the
shared facade behavior; see [Error handling](https://swiftaisdk.github.io/SwiftAISDK/core/error-handling/) and
[Telemetry](https://swiftaisdk.github.io/SwiftAISDK/core/telemetry/).

ElevenLabs provider options:

| Model | Keys |
| --- | --- |
| Music | `musicLengthMs` (3,000–600,000), `compositionPlan`, `forceInstrumental`, `respectSectionsDurations`, `storeForInpainting`, `signWithC2PA`, `withTimestamps`, `outputFormat` |
| Sound effects | `promptInfluence` (0–1), `loop`, `outputFormat` |

A `compositionPlan` replaces the prompt. `withTimestamps: true` switches music
to the detailed endpoint and returns lyric word timings under
`providerMetadata["elevenlabs"]`. The [ElevenLabs guide](https://swiftaisdk.github.io/SwiftAISDK/providers/elevenlabs/)
documents composition plans and timestamp metadata.

## Result

`AudioGenerationResult` contains:

- `audio`: the generated bytes.
- `contentType`: the response media type.
- `rawValue`: decoded JSON for detailed responses, otherwise `.null`.
- `warnings` and `providerMetadata`.
- `requestMetadata` and `responseMetadata`.

## Errors and limitations

- A provider option with the wrong type or outside its range throws
`AIError.invalidArgument` before any request is sent, naming the key, for
example `providerOptions.elevenlabs.promptInfluence`.
- `providerOptions.elevenlabs` must be an object. Keys that a model does not
support are dropped rather than sent; use `extraBody` to pass a raw field.
- Non-2xx responses throw `AIError.apiCall` with the status code, headers and
body; ElevenLabs `detail` text becomes the error message.
- A response with empty audio throws `AINoOutputError`.
- These models return a single audio payload; there is no streaming variant.
