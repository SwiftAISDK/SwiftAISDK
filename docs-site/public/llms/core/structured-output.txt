# Structured output

Source URL: https://swiftaisdk.github.io/SwiftAISDK/core/structured-output/

Use structured output when your app needs a Swift value rather than free-form prose.
Pass an `Output` strategy to `generateText` or `streamText`; the result's
`output` is the decoded value.

```swift
import SwiftAISDK

struct Summary: Decodable, Sendable {
    var title: String
    var bullets: [String]
}

let schema = AIJSONSchema<Summary>(
    [
        "type": "object",
        "properties": [
            "title": ["type": "string"],
            "bullets": ["type": "array", "items": ["type": "string"]],
        ],
        "required": ["title", "bullets"],
    ],
    name: "summary"
)

let provider = try AIProviders.openAI()
let model = try provider.languageModel("gpt-6.1-sol")

let result = try await model.generateText(
    "Summarize the SwiftAISDK README.",
    output: Output.object(schema: schema)
)

print(result.output.title)
```

`Output` covers text, object, array, choice and JSON strategies.

## Object facades

`generateObject` and `streamObject` remain callable and return the same decoded
values:

```swift title="Examples/Sources/StructuredOutput/main.swift"
import SwiftAISDK

struct Summary: Decodable, Sendable {
    var title: String
    var bullets: [String]
}

@main
struct StructuredOutputExample {
    static func main() async throws {
        let schema = AIJSONSchema<Summary>(
            [
                "type": "object",
                "properties": [
                    "title": ["type": "string"],
                    "bullets": [
                        "type": "array",
                        "items": ["type": "string"],
                    ],
                ],
                "required": ["title", "bullets"],
            ],
            name: "summary"
        )

        let provider = try AIProviders.openAI()
        let model = try provider.languageModel("gpt-6.1-sol")

        let result = try await model.generateText(
            "Summarize the SwiftAISDK README.",
            output: Output.object(schema: schema)
        )

        print(result.output.title)
    }
}
```

They emit the deprecation warnings `AISDK_DEP_GENERATE_OBJECT` and
`AISDK_DEP_STREAM_OBJECT`; prefer `Output` in new code. `Output` calls do not
emit these warnings even though they share the object machinery. The default
console logger emits each deprecation code once; custom warning loggers still
receive every warning.

## Output Strategies

- `Output.text()` returns plain text through the same result wrapper used by the other strategies.
- `Output.object(schema:as:)` validates JSON, decodes a `Decodable` Swift value, and keeps the raw output.
- `Output.array(element:minItems:maxItems:as:)` expects an `elements` envelope,
publishes optional array bounds in the generated JSON Schema, and rejects a
final result outside those bounds.
- `Output.choice(options:)` constrains output to one of the provided strings.
- `Output.json()` returns schema-free `JSONValue`.

All strategies preserve text, reasoning, usage, warnings, provider metadata, response metadata, and the underlying `TextGenerationResult`.

A provider may set `TextGenerationResult.structuredOutputText` to select the
JSON answer while retaining all generated text and content. OpenAI Responses
selects the last `final_answer` message for JSON requests. A nil selection falls
back to concatenated text; an empty selection is explicit and can fail parsing.
Plain text output continues to expose every draft and final message. JSON and
reasoning extraction middleware transform the selected text alongside content.

```swift
let labels = Output.array(
    element: ["type": "string"],
    minItems: 2,
    maxItems: 4,
    as: String.self
)
```

The constructor does not throw. A negative bound or `minItems > maxItems` is
rejected when generation or streaming begins, before the model performs work.

## Streaming Output

`streamText(..., output:)` maps language stream parts into `AIOutputStreamPart`:

- `textDelta` for raw text deltas
- `partialOutput` for incremental structured values when available
- `output` for the final validated output
- `source`, `warning`, `metadata`, `responseMetadata`, `finish`, and `raw` for surrounding stream state

Partial objects use Swift partial JSON repair. Array streams commit an element
when the next element starts or the enclosing object closes. Raw and typed
partial arrays contain the same committed elements. Updates follow text chunks,
which the object facade may coalesce; one chunk can commit several elements
together. The last element remains pending until its boundary is confirmed.

Typed object and array streams accept the same `streamRetries` option as raw
`streamText`; see [Retry behavior](https://swiftaisdk.github.io/SwiftAISDK/core/stream-text/#retry-behavior).

## Repair Hooks

The object facades and `Output` strategies can use `repairText` to make one model output repair attempt after invalid JSON, schema validation, or decoding failures. Errors carry `AIObjectGenerationError` context including the strategy, failure kind, generated text, and whether repair was attempted.
