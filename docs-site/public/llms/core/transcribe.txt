# Transcribe audio

Source URL: https://swiftaisdk.github.io/SwiftAISDK/core/transcribe/

Use `transcribe` when you have audio data and want normalized text back.

```swift title="Examples/Sources/TranscribeAudio/main.swift"
import Foundation
import SwiftAISDK

@main
struct TranscribeAudioExample {
    static func main() async throws {
        let provider = try AIProviders.openAI()
        let model = try provider.transcriptionModel("gpt-4o-transcribe")
        let audio = try Data(contentsOf: URL(fileURLWithPath: "meeting.wav"))

        let result = try await model.transcribe(
            audio: audio,
            fileName: "meeting.wav",
            mimeType: "audio/wav",
            language: "en",
            prompt: "The speakers discuss Swift package design."
        )

        print(result.text)
    }
}
```

To build the request separately, create an `AudioTranscriptionRequest`:

```swift
let request = AudioTranscriptionRequest(
    audio: audio,
    fileName: "clip.m4a",
    mimeType: "audio/mp4"
)

let result = try await AI.transcribe(model: model, request: request)
```

## URL audio and word timings

Use `AudioURLTranscriptionRequest` for remote audio. The model can accept the URL
directly; otherwise the facade downloads it through the validated download
transport and retries transcription with the same downloaded bytes. Request
headers authenticate the provider and are not forwarded to the audio host.
Supplying an explicit `download` callback selects local download processing.

```swift
let result = try await AI.transcribe(
    model: model,
    request: AudioURLTranscriptionRequest(
        audio: URL(string: "https://example.com/clip.wav")!,
        timestampGranularities: [.word, .segment]
    )
)
```

Binary `AudioTranscriptionRequest` also accepts `timestampGranularities`.
`TranscriptionResult.words` and `segments` contain normalized text and start/end
seconds when supported by the provider. Unsupported timing requests produce
provider warnings; requesting timings does not guarantee their availability.

## Streaming Transcription

`StreamingTranscriptionModel` is the duplex WebSocket counterpart to batch
transcription. Feed microphone or other incremental PCM chunks through an
`AIStreamingAudioInput` pipe and consume partial/final transcript events while
audio is still being produced:

```swift
let cartesia = try AIProviders.cartesia()
let model = try cartesia.streamingTranscription("ink-2")
let audioPipe = AIStreamingAudioInput.makeStream()

let result = try await model.stream(StreamingTranscriptionRequest(
    audio: audioPipe.input,
    inputAudioFormat: AIStreamingAudioFormat(
        mediaType: "audio/pcm",
        sampleRate: 16_000
    )
))

Task {
    for await chunk in microphonePCMChunks {
        _ = audioPipe.writer.send(chunk)
    }
    audioPipe.writer.finish()
}

for try await part in result.stream {
    switch part {
    case let .transcriptPartial(_, text, _, _, _, _):
        print("partial:", text)
    case let .transcriptFinal(_, text, _, _, _, _):
        print("final:", text)
    case let .finish(summary):
        print("complete:", summary.text)
    default:
        break
    }
}
```

Cartesia Ink 2 obtains a short-lived STT access token, supports server turn
detection or explicit finalization, maps partial/final events, and redacts the
access token from request metadata. Gateway uses the shared transcription
WebSocket envelope, splits audio frames at 64 KiB, and exposes
`experimentalTranscription.getToken(...)` for minting short-lived route-bound
client tokens on a trusted server. The underlying
`AIDuplexWebSocketTransport` is injectable for deterministic tests or custom
networking; stopping consumption, `result.cancel()`, or an `AIAbortSignal`
closes the socket and the audio producer.

[Deepgram](https://swiftaisdk.github.io/SwiftAISDK/providers/deepgram/) v1 Listen and
[Mistral](https://swiftaisdk.github.io/SwiftAISDK/providers/mistral/) Voxtral also implement the native streaming
contract, including injected duplex transports, handshake/finalization and
producer/socket cancellation. See their provider guides for raw formats and
provider-specific options. [Cartesia](https://swiftaisdk.github.io/SwiftAISDK/providers/cartesia/) and
[Gateway](https://swiftaisdk.github.io/SwiftAISDK/providers/gateway/) document their token flows. Azure's OpenAI transcription route delegates to the
configured native WebSocket transport.

Streaming transcription is intentionally narrower than a full bidirectional
speech session. For audio/text responses, function-call events, and session
configuration, use [Realtime sessions](https://swiftaisdk.github.io/SwiftAISDK/core/realtime/), which xAI, OpenAI Live,
Google Gemini Live and Gateway support. ElevenLabs realtime transcription and
Google/OpenAI streaming translation are not available.

## Vertex Gemini transcription

Vertex Gemini file models use generateContent and expose shared word timings.
`GoogleVertexProvider.streamingTranscriptionModel` adds Gemini Live transcription
with 16 kHz PCM, project/location and OAuth credentials. Express Mode keys do not
authenticate that live route. Input waits for setup acknowledgment, interim text
may be revised, and cancellation stops the producer/socket. See the [Vertex guide](https://swiftaisdk.github.io/SwiftAISDK/providers/google-vertex/)
for namespace precedence, timing warnings and quiet-grace finalization.

## Options

- `fileName` and `mimeType` describe the submitted audio.
- `language` hints the expected language when the provider supports it.
- `prompt` gives the model context for names, vocabulary, or formatting.
- `timestampGranularities` requests word or segment timings.
- `providerOptions` carries provider-specific transcription settings.
- `inputAudioFormat` declares the raw encoding and sample rate for streaming models.
- `extraBody`, `headers`, `abortSignal`, `retryPolicy`, and `telemetry` follow the
shared facade behavior; see [Error handling](https://swiftaisdk.github.io/SwiftAISDK/core/error-handling/).

### OpenAI

`chunkingStrategy` accepts `"auto"` or a `server_vad` object with an optional
threshold and nonnegative prefix/silence padding. The
`gpt-4o-transcribe-diarize` model defaults to automatic chunking and
`diarized_json` output.

### Azure MAI Transcribe

Azure MAI Transcribe 1.5/2 file models use the Speech endpoint; they expose
timed segments, duration, a language only for a single ISO-639-1 locale, and
`providerMetadata.azure.phrases`. Options under `providerOptions.azure` include
`timestamps`, `transcribeStyle`, one-element `locales`, `diarization.enabled`,
and `phraseList.phrases`. Unknown options fail before a request is sent.

MAI Transcribe 2 streaming accepts mono 16-bit PCM at 16 or 24 kHz. The model
performs the session handshake, sends audio incrementally, commits after input
ends, and cancels the socket and audio producer on abort or early close:

```swift
let azure = try AIProviders.azure(resourceName: "my-resource")
let model = try azure.streamingTranscriptionModel("mai-transcribe-2-streaming")
let result = try await AI.streamTranscribe(
    model: model,
    request: StreamingTranscriptionRequest(
        audio: audioPipe.input,
        inputAudioFormat: .init(mediaType: "audio/pcm", sampleRate: 24_000),
        providerOptions: ["azure": ["language": "en"]]
    ),
    telemetry: .init(integrations: [integration])
)
```

`AzureOpenAIAudioSettings` configures separate `speechBaseURL`, `maiBaseURL`,
and an injectable `webSocketTransport`. `ProviderSettings.baseURL` configures
the OpenAI endpoint. MAI file and streaming models have separate routes;
`mai-transcribe-2-streaming` does not support file transcription. See the
[Azure guide](https://swiftaisdk.github.io/SwiftAISDK/providers/azure/).

## Results

`TranscriptionResult` includes text plus optional timing and language metadata:

- `text`
- `words` and `segments`
- `language`
- `durationInSeconds`
- `usage`
- `warnings`
- `providerMetadata`
- `requestMetadata`
- `responseMetadata`

`usage` preserves optional provider-native billing JSON, including tokens or
seconds. `StreamingTranscriptionFinish.usage` preserves stream usage when the
provider supplies it. `AI.streamTranscribe` records start and one terminal
telemetry event; its byte length counts only audio consumed by the model.

For diarized OpenAI output, normalized text remains in the shared result while
speaker-aware segments are retained under
`providerMetadata["openai"]["segments"]` with text, start/end seconds, and
speaker identity.
