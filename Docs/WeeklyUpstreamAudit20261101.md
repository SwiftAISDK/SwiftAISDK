## Swift release scope

48 changed units are candidates: core 1.1.0 to 1.2.0, Anthropic 1.1.0 to 1.2.0 and 46 units 1.0.0 to 1.1.0. These are additive native APIs and compatible behavior fixes; npm versions do not set Swift versions. ByteDance, LMNT, Vercel and UI remain unchanged. MCP retains its existing core 1.0.0 minimum; async-credential providers require core 1.2.0 and new owning helpers raise the corresponding direct dependency minimums.

The compatibility facade adds forwarding signatures and raises installation minimums for the new APIs. It therefore requires a separate umbrella 3.1.0 release after dependency publication and verification. This is not an automatic umbrella release for a provider-only change.

## Retained gaps and native adaptations

- Async credential suppliers run only when their authentication header survives overrides and origin stripping. Explicit custom authentication skips an unused callback; JS header-factory callback side effects are not replicated.
- Native prompt/tool-loop maxSteps defaults remain five, agents twenty and the direct request overload one. Set explicit limits for steering.
- Model metadata describes support; it does not validate calls or imply every provider publishes a complete catalog.
- Google speech translation/realtime and other pre-existing provider gaps are unchanged. Public string model IDs and native Foundation/Sendable APIs replace TypeScript catalogs/promises.
- Browser iframe/React rendering, Node/Edge tracing, workflow/harness/sandbox execution and JS low-memory getter/replay semantics are separate products.
- MCP input-required handles form elicitation; URL elicitation and sampling fail explicitly.
- No paid live provider calls were run. Offline fixtures do not prove current live-service behavior.
